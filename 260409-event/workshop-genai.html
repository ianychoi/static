HANDS ON - 1

GenAI on EKS using NVIDIA GPUs

Workshop - 오전 · 10:30 - 13:50 (점심시간 포함) · 18.100호
Overview

이 워크샵에서는 Amazon EKS에서 대규모 언어 모델(LLM) 애플리케이션 및 추론을 시작하는 방법을 배웁니다. 프로덕션 수준의 LLM 워크로드를 배포하고 관리하는 방법을 알아보세요. 실습을 통해 Amazon EKS와 AWS 서비스 및 오픈소스 도구를 활용하여 강력한 LLM 솔루션을 구축하는 방법을 탐색할 수 있습니다. 워크샵 환경은 필요한 모든 인프라와 도구를 제공하여 학습과 구현에만 집중할 수 있도록 합니다.

워크샵 실습

워크샵은 네 가지 주요 카테고리로 구성되어 있습니다:

1. 시작하기
모듈설명소요 시간
자율 학습 설정 자율 학습 워크샵을 위한 환경을 설정합니다. 자체 AWS 계정을 사용하는 경우에만 이 모듈을 따르세요. 45분
AWS 이벤트에서 AWS 주최 이벤트 참석자를 위한 지침입니다. AWS 주최 이벤트에 참석 중인 경우에만 이 모듈을 따르세요. 5분
2. 소개
모듈설명소요 시간
환경 탐색 워크샵 환경을 파악하고 구축하게 될 솔루션의 아키텍처를 이해합니다. 10분
LLM 추론을 위한 GPU 인프라 최적화 GPU 인스턴스를 위한 온디맨드 용량 예약(ODCR) 구성, EKS Auto Mode를 통한 동적 프로비저닝 설정, SOCI 스냅샷터를 통한 컨테이너 시작 가속화 방법을 배웁니다. 이 최적화된 기초는 모든 LLM 워크로드에 대한 효율적인 GPU 활용을 보장합니다. 15분
3. Amazon EKS에서의 추론
모듈설명소요 시간
vLLM 모델 로딩 GPU 인프라를 기반으로 vLLM을 사용하여 LLM 추론을 배포하고 최적화합니다. vLLM은 추론 처리량과 지연 시간을 크게 향상시키는 오픈소스 라이브러리입니다. GPU 활용도를 극대화하면서 LLM 모델을 효율적으로 서빙하는 방법을 배웁니다. 30분
LLM 추론 워크로드 관찰하기 NVIDIA DCGM, Prometheus, Grafana와 같은 도구를 사용하여 LLM 배포에 대한 포괄적인 관찰 가능성을 구현합니다. 배포된 LLM 워크로드의 GPU 활용도, 모델 성능 및 애플리케이션 메트릭을 모니터링하고 분석합니다. 40분
4. Amazon EKS에서의 고급 AI
모듈설명소요 시간
vLLM과 Ray를 사용한 LLM 추론 확장 vLLM과 분산 컴퓨팅 프레임워크인 Ray를 결합한 고급 확장 기법을 탐색합니다. 여러 추론 요청을 효율적으로 처리하고 분산 워크로드를 모니터링하는 방법을 배웁니다. 45분
Strands 에이전트 Strands를 사용하여 Amazon EKS에서 몇 단계만으로 에이전트를 생성하고 배포하는 방법을 배웁니다. 쿠버네티스에서 AI 에이전트를 배포하는 간소화된 접근 방식으로, 대규모로 자율 AI 에이전트를 구축하고 관리하는 것을 간단하게 만듭니다. 20분
