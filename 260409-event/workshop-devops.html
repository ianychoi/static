AWS DevOps Agent Workshop: Amazon EKS Incident Response

Workshop - 오전 · 10:30 - 13:50 (점심시간 포함) · 18.100호

본 워크숍은 AWS DevOps Agent - EKS Troubleshooting Workshop 내용을 기반으로 실습합니다.

Overview

AWS DevOps Agent EKS Troubleshooting Workshop에 오신 것을 환영합니다!

이 실습 워크샵에서는 AWS DevOps Agent를 사용하여 Amazon EKS 환경에서 인시던트 대응을 가속화하고 문제를 해결하는 방법을 배웁니다. 멀티 서비스 리테일 애플리케이션이 이미 EKS에 배포되어 있으며, 실행 중인 애플리케이션에 실제 장애를 주입하고 DevOps Agent를 사용하여 문제를 조사하고 해결하게 됩니다.

🎯 What You'll Learn
  • Amazon EKS에 배포된 프로덕션 수준의 마이크로서비스 애플리케이션 검토
  • EKS 인프라를 모니터링하도록 AWS DevOps Agent 구성
  • 장애 주입을 통한 카오스 엔지니어링 실험 실행
  • DevOps Agent를 사용하여 인시던트를 조사하고 근본 원인 파악
  • 권장 완화 조치를 적용하여 문제 해결
